# Snakrrr

A minimal Python system info-fetcher that displays only essential information without bloat.

![Preview](https://github.com/user-attachments/assets/3eace1ee-6e55-459c-9ef9-0a0b0f7bcd01)

## Features

- cool snake!
- useful info

## Installation

### Via PyPI
```bash
pip install snakrrr
```

### From Source
```bash
git clone https://github.com/Sharpnesse49/Snakrrr
```

## Usage

```bash
snakrrr
```

## Why?

This tool is inspired by [fastfetch](https://github.com/fastfetch-cli/fastfetch), and is meant to be placed in the `.bashrc` file to launch with the terminal. It is used to see if you have to update (kernel-wise), what RAM and storage amount you're using, etc.
